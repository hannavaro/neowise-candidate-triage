# Входящие заявки

Вставьте сообщение клиента и нажмите «Разобрать заявку». Страница покажет тему и предложит черновик. Менеджер читает его, при необходимости правит и сам отвечает клиенту.

## Как запустить

Установите Node.js 20 или новее и выполните команду из папки проекта.

```sh
node server.mjs
```

Затем откройте [страницу в браузере](http://127.0.0.1:3000). Здесь работает локальный имитатор AI, поэтому ключи и установка пакетов не нужны. Если порт 3000 занят, задайте другой через переменную `PORT`.

## Как проверить

На странице нажмите «Подставить пример», а затем «Разобрать заявку». Должны появиться тема «Доставка» и черновик. Теперь введите `[timeout]` и отправьте ещё раз. В карточке результата появится «Нужен ручной разбор», а предыдущий черновик исчезнет. Сам текст заявки останется в форме.

Метки `[error]`, `[bad-json]`, `[bad-topic]` и `[empty-draft]` имитируют другие сбои.

```sh
node --test
```

Тесты поднимают свой сервер на свободном порту. Они проверяют неверный ввод, три темы и все пять вариантов сбоя.

## Что возвращает API

`POST /api/triage` принимает JSON с полем `text`. Если там пустая строка, число или поля вообще нет, сервер вернёт HTTP 400 с `invalid_input`. То же произойдёт, если JSON не читается.

Сервер даёт имитатору 300 мс. Он проверяет ответ и возвращает `ready`, только если у заявки есть тема (`delivery`, `pricing` или `other`) и непустой черновик. При сбое вернётся `manual_review`, а `topic` и `draft` будут равны `null`. В обоих случаях HTTP-статус 200.

Пользу подсказки можно оценить по времени от открытия заявки до готового ответа. Сравните медиану для заявок, которые менеджер разобрал с черновиком и без него.
