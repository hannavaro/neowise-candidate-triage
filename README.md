# Neowise. AI-помощник для входящих заявок

Менеджер вводит текст заявки, получает тему и черновик и решает, какой ответ отправить клиенту.

## Запуск

Нужен Node.js 20 или новее. Внешние зависимости и API-ключи не требуются.

```sh
node server.mjs
```

Откройте [страницу входящих заявок](http://127.0.0.1:3000). Порт можно задать переменной окружения `PORT`.

## Тесты

```sh
node --test
```

Тесты сами запускают сервер на свободном локальном порту. Они проверяют пустой, нестроковый и некорректный JSON-ввод, все три допустимые темы и пять сценариев сбоя имитатора.

Для проверки страницы сначала введите «Когда будет доставка?», затем отправьте новую заявку с одной из меток `[timeout]`, `[error]`, `[bad-json]`, `[bad-topic]`, `[empty-draft]`. После второго запроса появится сообщение о ручном разборе, а прежние тема и черновик исчезнут.

## Поведение API

`POST /api/triage` принимает JSON с полем `text`. При некорректном вводе сервер отвечает HTTP 400 с `{"status":"invalid_input"}`.

Сервер прерывает ожидание имитатора через 300 мс и проверяет, что ответ является JSON, тема входит в `delivery`, `pricing`, `other`, а черновик содержит текст. При успехе API возвращает HTTP 200 с `status: "ready"`, темой и черновиком. Таймаут, ошибка и неподходящий ответ дают HTTP 200 с `{"status":"manual_review","topic":null,"draft":null}`.

Черновик сокращает время на подготовку ответа менеджером. Эффект можно измерить по медианному времени от открытия заявки до готового ответа до и после внедрения.
